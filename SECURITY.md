# Security Policy

## Report a vulnerability

Don’t open a public issue for a suspected security or privacy problem.

Email `support@organizedglitter.app` with the subject **Security report**.
Include:

- A clear description of the problem and its impact
- The affected commit or app version
- The smallest safe set of steps needed to reproduce it
- Any suggested fix or mitigation

Don’t include credentials, authentication tokens, customer data, private file
URLs, or copies of private files. If sensitive evidence is necessary, describe
what you have and wait for a safe way to share it.

## Testing boundaries

- Don’t test against the production service without written permission.
- Don’t access, change, download, or retain another user’s data.
- Don’t attempt denial-of-service, social-engineering, or physical attacks.
- Use local services, disposable accounts, and records you own.

We’ll acknowledge reports as soon as practical and coordinate disclosure after
the problem has been investigated and addressed.

## Supported versions

Organized Glitter for iOS is still under development. Security fixes are made
on the latest `main` branch. No public iOS release is currently supported.
